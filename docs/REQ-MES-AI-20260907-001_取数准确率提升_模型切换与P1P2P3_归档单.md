## D. 部署配置（非代码，随部署设置）

网关环境变量需设置：
```
AI_PROVIDER=kimi
AI_API_BASE_URL=https://api.moonshot.cn/v1
AI_MODEL=kimi-k3
AI_API_KEY=<Kimi key，禁硬编码>
SCHEMA_LINKING_ENABLED=true
```
> kimi-k3 为推理模型：provider 已自动把 temperature 夹到 1、max_tokens 兜底 2048、正文空回退 reasoning_content。
> 注意 kimi-k3 单次 mes-sql 约 30~60s，线上延迟高于旧模型。
