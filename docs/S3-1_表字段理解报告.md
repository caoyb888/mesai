## 二、训练方法

1. **语义拼图**（应对零注释活库）：每张表卡片合成 字段类型 + 字典 semantic（英/韩）+ 命名规约 + 被读写过程热度画像；Kimi 按优先级推断字段语义，**缺失/存疑一律标「待补充」，禁止臆断**。
2. **三语归一**：英文/韩文语义译中并保留原文（如 코일→钢卷、제품종합판정등급→最终判定等级）。
3. **防 owner 前缀误导**：卡片头部明确 owner=MESAPUSER 是 schema 用户名非表名前缀（CLAUDE.md 14.2 Oracle 版）。
4. 每张表输出：表用途 / 核心字段语义 / 状态类型标志字段（标「待字典解码」）/ 主键与疑似关联键 / 语义存疑字段清单。
