## 二、训练方法

1. **拓扑序**（小行数底层函数优先），逐子程序输出：**用途 / 业务规则 / 状态流转 / 读写副作用 / 调用依赖 / 风险与不确定点**。
2. **动态 SQL 专项**：`EXECUTE IMMEDIATE` / 拼接 SQL 明确标注「静态分析盲区」，不臆断表依赖。
3. **去重**：厂区/产线变体包（_LZ/_RZ/_SHIP/_YC/_YC1）若基包在集内则只训基包，**跳过 79 个变体子程序**（如 BSQM_MTC_ISSUE 6 变体→留 1）省 token。
4. **全链路脱敏**：源码经网关脱敏后外发（P0 源码已认证 0 真实 PII）。
