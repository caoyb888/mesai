## 二、方法论与证据来源（含脱敏合规）

**四类静态证据**（均来自真实库，非臆造）：
1. **状态写入**：P0 过程 `UPDATE...SET 列=字面量` → 状态取值与触发过程（T3-3-1）。
2. **表结构共键**：同一表同时承载两实体键 = 父子血缘桥表（T3-3-2）。
3. **过程读写血缘**：过程「读上游载体表 / 写下游载体表」= 业务传播（T3-3-2）。
4. **调用编排 + 源码注释**：子程序调用链 + 中/韩文注释业务意图（T3-3-3）。

**合成与合规**：证据经 **ai-gateway 唯一外发咽喉**（CLAUDE.md §4.2 全 7 类脱敏门强制）交 Kimi 合成；表名/列名/过程名为 schema 标识符非 PII，脱敏引擎精准锚定不误伤（见 `desensitize_audit_report.md`「可外发」认证）。

   - 根据综合判定结果，签发质保书，关键表包括`SQM_MTC_REQ`, `SQM_WSP_MTC_CHEM_INF`, `SQM_WSP_MTC_COM_INF`, `SQM_WSP_MTC_MECH_INF_1`, `SQM_WSP_MTC_MECH_INF_2`, `SQM_WSP_MTC_MECH_INF_3`。
   - 状态：质保书签发。

#### 流程组之间的编排关系

- **试样批次(LOT)成形与检验结果**触发**标准力学性能试验与判定**，共享检验结果表`SQM_SMP_LOTFORM_RSLT`。
- **标准力学性能试验与判定**触发**综合判定(总判)**，共享力学性能判定结果。
- **综合判定(总判)**触发**质保书(材质证明书 MTC)签发**，共享综合判定结果。

#### 全流程的关键业务规则与「待确认」清单

- **关键业务规则**：
  - 检验结果必须符合预定标准，否则触发不合格品处理流程。
  - 力学性能试验结果必须在规定范围内，否则判定为不合格。
  - 综合判定结果决定是否签发质保书。

- **待确认清单**：
  - **标准力学性能试验与判定**流程中涉及的具体表和状态。
  - 动态SQL和跨包调用的具体逻辑和影响。

### 生产调度 核心流程总览

#### 端到端主流程

1. **生产计划调整** → **计划时间排程** → **计划查询与批次选择** → **计划结果确认** → **生产指令下达** → **厚板作业指令** → **板坯批处理作业**

   - **生产计划调整**：调整生产计划，关键写表 `SCH_INST_ROLL`, `SCH_PLAN_HEAT`, `SCH_PLAN_ROLL`, `SCH_PLAN_SLAB`, `SCH_PLT_INST_CUTTING`, `SCH_PLT_INST_ROLL`。
   - **计划时间排程**：根据调整后的计划进行时间排程，关键写表 `SCH_HEAT_SCHEDULE`, `SCH_SLAB_SCHEDULE`, `SCH_TEMP_HEAT_SCHEDULE`。
   - **计划查询与批次选择**：查询计划并选择批次，关键写表待确认。
   - **计划结果确认**：确认计划结果，关键写表 `SCH_CAST_DESIGN_RESULT`, `SCH_CC_WORK_DETAIL_INFO`, `SCH_HSM_ROLL_DESIGN_SLAB`, `SCH_HSM_ROLL_DESIGN_SLABT`, `SCH_HSM_WORK_DETAIL_INFO`, `SCH_MPLATE_WORK_DETAIL_INFO`。
   - **生产指令下达**：下达生产指令，关键写表 `SCH_INST_HEAT`, `SCH_INST_HEAT_PREV`, `SCH_INST_SLAB`, `SCH_PLAN_HEAT`, `SCH_TEMP_PROD_INST`。
   - **厚板作业指令**：生成厚板作业指令，关键写表 `SCH_PLAN_CUT_TEMP`, `SMS_SLAB`。
   - **板坯批处理作业**：进行板坯批处理作业，关键写表 `SCH_PLAN_MPLATE`, `SCH_SLAB_DESIGN_ORD`, `SCH_SLAB_DESIGN_RESULT`。

#### 流程组之间的编排关系

- **生产计划调整**触发**计划时间排程**，共享`SCH_PLAN_HEAT`, `SCH_PLAN_ROLL`, `SCH_PLAN_SLAB`。
- **计划时间排程**触发**计划查询与批次选择**，共享`SCH_HEAT_SCHEDULE`, `SCH_SLAB_SCHEDULE`。
- **计划查询与批次选择**触发**计划结果确认**，共享待确认。
- **计划结果确认**触发**生产指令下达**，共享`SCH_PLAN_HEAT`, `SCH_INST_HEAT`, `SCH_INST_SLAB`。
- **生产指令下达**触发**厚板作业指令**，共享`SCH_INST_HEAT`, `SCH_INST_SLAB`。
- **厚板作业指令**触发**板坯批处理作业**，共享`SCH_PLAN_MPLATE`。

#### 全流程的关键业务规则与「待确认」清单

- **关键业务规则**：
  - 生产计划的调整必须在时间排程之前完成。
  - 计划结果的确认是下达生产指令的前提。
  - 生产指令下达后，才能进行厚板作业指令的生成。
  - 厚板作业指令完成后，才能进行板坯批处理作业。

- **待确认**清单：
  - 计划查询与批次选择：关键写表待确认。
  - 动态 SQL：可能存在跨包调用或动态 SQL，具体细节待确认。
