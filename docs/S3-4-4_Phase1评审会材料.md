## 二、Phase-1 交付一览（汇报要点）

**对象系统**：真实钢板/卷材 MES（韩系，Oracle 21c XE，owner=MESAPUSER），**1,860 表 / 78,526 字段 / 9,160 PL/SQL 单元 / 约 193 万行**；克隆库列注释全空、三语混合、无历史文档。

**三大理解成果（P0 核心资产）**：
- 表/字段：**95 表卡片**（语义 87%）；SQL 验证 30 题（自动初评 69.9）。
- 存储过程：**1308 / 1309 卡片**（Top60 P0 包切分子程序）。
- 业务流程：状态机 **34** 字段、追溯 **14** 实体键 **13** 边、核心流程 **12** 组、验证题 **21** 道（接地 26/26 全命中）。

**知识资产与工程能力**：
- 中韩英术语 **9,698** + 代码字典；断言种子 **657** 条入 `/assertions/`。
- 知识库 RAG **5,155 chunk** 可召回；全链路**脱敏 0 命中**「可外发」认证。
- 工具链（自省/建图/切分/解析/对账/训练/理解/验证/报告），纯 stdlib、单测齐备。
