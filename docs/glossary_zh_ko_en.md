> 生成方式：逐格 Unicode 语种判定，纯标准库，**未调用外部 AI**。

## 一、方法说明

本 MES 为韩系系统，代码字典中 `CD_NM` 多为中文本地化名、`CD_DESC` 多为韩文，
但存在英文混入、语言错位、空值等情况（**列 ≠ 语言**）。故本表对每个候选值
按字符 Unicode 区段逐格判定语种（韩文谚文 / CJK 表意 / 拉丁字母），
再落位到「中 / 韩 / 英」三列，空缺列即为后续需补译的缺口。

**结构性说明**：源表每条仅 `CD_NM` / `CD_DESC` 两个名字列，单条最多承载两种
语言，故「三语齐全」天然为 0——本表由字典产出的是**双语对**（多为中-韩或
中-英），三语补全须由 Kimi 翻译第三语（T3-0-5 收尾，见第三节）。
实测该克隆字典已大量本地化为中文，韩文仅约占 1/5。
