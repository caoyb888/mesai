#### POST /auth/login

**功能**：用户登录
**说明**：用户名密码登录，连续失败 5 次锁定账号
**operationId**：`login`
**鉴权**：❌ 免鉴权接口

**请求体（application/json）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `accountNo` | string | ✅ |  |
| `password` | string | ✅ |  |
| `captchaToken` | string |  | 可选验证码 Token |

**响应（200）：** 登录成功或业务错误（用户名密码错误等）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | integer | ✅ | 业务状态码，6 位数字 |
| `message` | string | ✅ | 提示信息（中文） |
| `data` | object | ✅ | 业务数据，失败时为 null |
| `traceId` | string | ✅ | 链路追踪 ID |
| `data` | object(LoginResponseData) |  |  |
| `data.accessToken` | string |  |  |
| `data.refreshToken` | string |  |  |
| `data.expiresIn` | integer |  | Access Token 有效期（秒），默认 7200 |
| `data.userInfo` | object(UserBasicInfo) |  |  |
