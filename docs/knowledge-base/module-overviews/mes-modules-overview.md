## 模块 01：基础数据管理（Master Data Management）

### 业务定位
基础数据是整个 MES 系统的数据基础，定义了产品、物料、工位、设备等核心主数据。
所有业务模块均依赖本模块的数据。

### 核心实体
- **产品（Product）**：被生产的终品，有唯一产品编码
- **物料（Material）**：原材料、半成品，含 BOM 结构
- **BOM（Bill of Materials）**：产品物料清单，定义产品由哪些物料组成及用量
- **工位（Workstation）**：生产执行的地点，属于产线
- **班组（Shift/Team）**：操作员的组织单位
- **客户（Customer）**：订单来源方

### 关键业务规则
- 产品编码全局唯一，一经创建不可修改（变更需新建版本）
- BOM 存在版本概念，同一产品可有多版 BOM，但同一时间只有一个生效版本
- 工位归属于产线，产线归属于车间，构成三级组织结构

## 模块 02：工艺管理（Process Management）

### 业务定位
定义产品从原材料到成品的生产工艺路径，包括工序顺序、工序标准、标准工时等。

### 核心实体
- **工艺路线（Process Route）**：产品的生产路径，由多个工序组成
- **工序（Operation）**：单一生产步骤，在特定工位执行
- **标准工时（Standard Time）**：每道工序的标准加工时间（秒/件）
- **工艺参数（Process Parameter）**：工序执行时的控制参数（温度/压力等）

### 关键业务规则
- 工艺路线与产品绑定，产品不同则工艺路线不同
- 工序有顺序编号（seq），必须按顺序执行（除非标注"可并行"）
- 标准工时用于计算产能和排程，变更需经工艺工程师审批

## 模块 03：生产计划管理（Production Planning）

### 业务定位
根据客户订单和库存情况，制定生产计划，分解为可执行的生产工单，并进行排程。

### 核心实体
- **生产计划（Production Plan）**：月/周维度的生产目标
- **生产工单（Work Order）**：具体的生产任务，含产品/数量/交期
- **排程（Schedule）**：工单在工位上的时间安排

### 关键业务规则
- 工单状态流转：草稿 → 已下达 → 执行中 → 完成/异常关闭
- 工单一旦"已下达"，数量不能减少（只能增加或分拆）
- 排程冲突（同一工位同一时间有两个工单）系统必须告警

## 模块 04：作业管理（Operation Management）

### 业务定位
记录生产过程中的实际执行情况，包括报工、在制品流转、异常处理等。

### 核心实体
- **报工记录（Work Report）**：操作员汇报完成了多少数量
- **在制品（WIP，Work In Process）**：当前在产线上未完工的产品批次
- **批次（Lot）**：生产追踪的最小单位，含物料批次号
- **异常记录（Exception Record）**：生产过程中的质量/设备/人员异常

### 关键业务规则
- 报工数量不能超过工单计划数量
- 在制品在工序间流转时需扫描条码确认
- 报工后自动更新工单完成率和在制品位置

---

## 模块 05：设备管理（Equipment Management）

### 业务定位
管理生产设备的台账、日常点检、维护保养和维修，确保设备可用率。

### 核心实体
- **设备台账（Equipment Master）**：设备基本信息（型号/序列号/所在工位）
- **点检计划（Inspection Plan）**：设备定期检查的计划（日/周/月）
- **点检记录（Inspection Record）**：实际执行点检的记录
- **维修工单（Maintenance Order）**：设备故障维修任务

### 关键业务规则
- 设备有"运行/停机/维修/报废"四种状态，停机和维修状态不能接受生产工单
- 点检超期（超过计划日期未点检）必须告警
- 设备序列号在系统中为唯一标识（脱敏后为 `[DEVICE_SN_***]`）

---

## 模块 06：质量管理（Quality Management）

### 业务定位
对生产过程和产成品进行质量检验，处理不良品，分析质量趋势。

### 核心实体
- **检验方案（Inspection Plan）**：定义对哪些产品/工序执行何种检验
- **检验记录（Inspection Record）**：实际检验结果，含检验项目明细
- **不良品（Defect）**：检验不通过的产品，记录不良类型和数量
- **返工/报废单（Rework/Scrap Order）**：不良品的处理方案

### 关键业务规则
- 检验有"全检"和"抽检"两种方式，抽检有抽样比例配置
- 关键工序（KQC）必须100%全检
- 不良品进入隔离区，必须有明确的处理结论（返工/让步接收/报废）才能关闭
