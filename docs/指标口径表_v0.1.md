## 1. 列语义

| 列 | 说明 |
|----|------|
| 精确计算公式_字段级 | 分子/分母/过滤条件写到 表.字段=值 级别；文字描述仅作补充 |
| sqlTemplate_绑定变量 | 可直接参数化执行的 Oracle SQL；`:dtm_*` 系 = 字符时间列（YYYYMMDDHH24MISS，字符比较），`:date_*` 系 = DATE 列（自然日闭开区间） |
| params | 绑定变量清单及格式约定 |
| 现成过程或报表 | 六安手册中的对应界面/报表号（人工核对入口）；**库内未发现现成汇总存储过程**，全部指标走 SQL 模板路线 |
| 参考值_测试库观测 | 均为测试库（2024 冻结窗）观测区间，**不是目标值**；目标值/告警阈值留待业务方按"归属与确认"列补签 |
| 归属与确认 | 建议归属部门 + 空签字栏 + 该指标涉及的裁决点编号 |

## 2. 待业务方裁决点（J1~J16，签字前必须逐项裁决）

同名多算法/含义存疑处已全部收敛为默认口径+裁决点，**默认口径可直接用，但裁决结果与默认不一致时须回改 CSV 并升版本**：

| # | 指标 | 裁决问题 | 当前默认 |
|---|------|----------|----------|
| J1 | M01 | HEAT_STS 空值（15,472 条）是否等同有效炉次 | 计入 |
| J2 | M01 | 炉次数按登记时间 CRT_TM 还是出钢时间 | CRT_TM |
| J3 | M05/M06 | 完工量是否仅计子板（PLT_NO 13 位），母板行（9 位）是否剔除 | 全部计入（有 FIN_SUMUP_DT 即计） |
| J4 | M07 | "取消装炉"操作是否物理回删 SPR_FCE_CHARGE 报文行 | 假定不回删，按报文条数计 |
| J5 | M08 | 同炉同元素多次判定（JDG_SEQ）按记录条数还是最终判定 | 按记录条数 |
| J6 | M10 | MTRL_NO 中与 SMS_HEAT.HEAT_NO 对不上的 26.5% 如何归属 | 仍按 distinct MTRL_NO 计 |
| J7 | M11 | 良率取当前判定值还是初判值（存在 40.5 万条判定变更记录） | 当前值（SQM_TOT_JDG_RSLT 现值） |
| J8 | M11 | 良率分母是否剔除自用坯（等级 4） | 不剔除 |
| J9 | M13 | 订单行状态 H（12 行）、F（4 行）不在码表，含义待补 | 不计入"在产" |
| J10 | M14 | 变更单（CHG_ORD_NO 非空）是否算新增订单 | 计入 |
| J11 | M16 | 发货完成率分母是否剔除取消单（Z） | 剔除 |
| J12 | M17 | APPR_JDG_YN 空值 139,190 行=未检还是不适用 | 视为未完成（进分母） |
| J13 | M03/M06 | SLAB_WGT / PLT_WGT 单位确认（现按吨推断） | 吨 |

| J15 | M12 | HOLD 无独立操作画面（六安手册未见），业务入口待确认 | 仅作数据面指标 |
| J16 | M15 | 入库吨位 join 口径：SYD_PROD_RECEIPT.PROD_NO = SPR_PLATE.PLT_NO 待核 | 暂只发布块数口径 |

**"昨天/上周"的界定**：库内未发现生产日历表；所有模板按**自然日**闭开区间实现。若业务按生产日（如早班 8:00 切日）统计，须业务方给出切日规则后统一改模板——这是全表级裁决点 J0。

## 4. 未收录指标及前置条件（第二批候选）

以下高频指标**本批不收**，原因是数据面或业务口径不具备，收录前须先解决前置：

| 指标 | 不收原因 | 前置条件 |
|------|----------|----------|
| OEE / 稼动率 | 库内无理论节拍来源；误工/停机表（SPR_DOWNTIME 等）在测试库 0 行（验收集 R03 即考此边界） | 业务方提供节拍基准 + 确认生产库误工数据面 |
| 计划达成率 | SCH_PLAN_*（计划板坯/计划钢板 25.5 万行）与实绩的对账键及"达成"定义未裁决 | 业务方定义分子分母（按块/按吨/按订单），我方再做数据面核验 |
| 交期兑现率 | SPG_ORD_DELV_DELEY（交期延误表）测试库 0 行 | 确认生产库有数 |
| 成材率 | 六安有 SPRE0010 报表概念，但坯耗归属（回炉/轧废/切损）口径未定义 | 业务方给出成材率定义式，再对 SPR_PLATE×SMS_SLAB 做键核验 |
| 化学成分实绩均值类 | "结果 SQM_CHEM_RSLT（102 万行）"与"判定 SQM_CHEM_JDG"是两码事：前者为分析实绩、后者为判定记录 | 实绩类指标需先裁决取样/复验取哪次（LIMS 委托链） |

## 5. 维护规则

1. 一指标一口径：新增别名往"别名与英文"列追加，**不得**为同名指标另开新行；算法分歧走 §2 裁决后改现有行。
2. 每次修改升版本号（v0.1→v0.2），并重跑 §3 互证表——验收题期望答案与口径公式对不上即视为口径未写清，禁止发布。
3. 业务方签字后，`归属与确认`列填实名+日期，该行口径即为唯一事实来源（对齐 docs/24 风险表第 3 条对策）。
